# Banco Horizonte

Sitio web estático y adaptable para un banco ficticio, creado como ejercicio académico. La identidad visual y el contenido son originales; no se ofrecen productos financieros reales.

## Archivos

- `index.html`: estructura semántica, navegación multinivel y contenido por sección.
- `styles.css`: identidad visual, diseño adaptable, transición de tema, atajos e ilustraciones CSS.

## Ver el sitio

Abre `index.html` en un navegador. El control «Modo oscuro» está dentro del menú principal.
No requiere instalación, servidor ni dependencias de JavaScript.

## Publicación

El proyecto está listo para conectarse a un repositorio Git y desplegarse como sitio estático en Vercel. Usa la carpeta del proyecto como raíz y deja los comandos de construcción y salida vacíos.
